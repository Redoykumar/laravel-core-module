2. **Click:** "Create a new release" or "Draft a new release"
3. **Select tag:** v1.0.0 (already created)
4. **Enter title:** `Release v1.0.0 - Initial Stable Release`
5. **Paste notes:** Copy from RELEASE_v1.0.0.md
6. **Publish:** Click "Publish release"

**That's it! Release is live!**

